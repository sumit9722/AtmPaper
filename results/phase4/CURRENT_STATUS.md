# Current phase 4 status

The retrospective computational work is complete and validated: the original same-year spatial/city comparisons plus the new [2024-to-2025 temporal supplement](temporal_v2/README.md).

The original README and `qa/phase4_status.json` are preserved as the version 1 release record; their missing-training-year statement describes that earlier release. The current temporal run uses 1,201 eligible 2024 sites and tests 1,192 sites in 2025. Fifteen temporal models and paired spatial-block uncertainty are available in `temporal_v2/`.

No temporal comparison passed the predefined AP-improvement gate. Completing an experiment does not mean its hypothesis passed. [Phase 5](../phase5/README.md) is therefore reported as descriptive transfer analysis.

Full confirmatory acceptance is still pending: independent crime/linkage and facility review, Buffalo coordinate precision, feature/continuity acceptance, and a genuinely uninspected later-period evaluation. The 2024 cohort additionally depends on the documented address-continuity amendment. Automated validation is not independent scientific sign-off.
