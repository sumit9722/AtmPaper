# Source completeness and missingness amendment

During Phase 2 QA, before any models, the historical NYPD source's reported-year coverage raised a potential late-report omission. Inspect the official current-year feed (5uac-w243) for 2022–2025 robbery/burglary occurrences, reconcile counts and source IDs, and combine any recovered records with qgea-i56i under the already frozen city-case deduplication rule. Preserve source paths and duplicates. Both feeds are current extracts, not historical database vintages. This changes source completeness, not outcome category, radii, ATM eligibility or evaluation criteria. If no qualifying rows are available, report that result without assuming future reports are impossible.

Buffalo's created_at is missing on many earlier records. The count with known report availability is a lower-information measure when other nearby cases have unknown report times. Add background_has_unknown_availability, background_report_date_coverage and background_measurement_status; preserve missing/late counts separately. A zero known-available count is not evidence that actual background crime or missing timestamps were zero. No model may silently treat an incomplete baseline as fully measured. Buffalo's nonmissing created_at remains an unverified ingestion-time proxy.
